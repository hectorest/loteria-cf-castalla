# Lotería de Navidad 2026 · CF Castalla

Formulario de reserva de décimos del número 79047 y panel privado del club.

- **Página:** GitHub Pages (`index.html`), sin datos guardados en el navegador.
- **Datos:** Supabase (proyecto `loteria-cf-castalla`, región París). El público solo puede crear reservas mediante la función `crear_reserva`; leer, modificar o borrar exige iniciar sesión con un usuario que figure en la tabla `admins`.
- La clave que aparece en el código es la clave *publicable* de Supabase, pública por diseño. Los permisos los aplica la base de datos.
- Los nombres y teléfonos se borran automáticamente cada noche a partir de la «fecha de borrado» de Ajustes.

Mientras no se marquen los textos legales como revisados, la página muestra el aviso «En pruebas».
